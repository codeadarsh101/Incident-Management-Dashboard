# Incident-Management-Dashboard

The app allows users to view, search, filter, sort and create incidents with a clean responsive UI.

🌐 Tech Stack

1. Frontend-->
   React (Vite)
   Tailwind CSS
   Axios

3. Backend-->
   Node.js
   Express.js
   Prisma ORM

4. Database-->
    PostgreSQL / MongoDB (replace with what you used)

4. ✨ Features-->

a. Incident Listing
b. View incidents in a responsive table layout
c. Server-side pagination
d. Sort incidents by Newest / Oldest
e. Sort incidents by Severity
f. Filter incidents by Status
g. Debounced search by title & summary

5. Incident Details
    Dedicated details page for each incident
    Displays full incident information

6. Create Incident
   Form to create new incidents
   Status & severity selection
   Form validation

7. UI/UX
   Fully responsive design (mobile + tablet + desktop)
   Built with TailwindCSS
   Clean and modern interface
